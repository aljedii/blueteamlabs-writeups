# Blue Team Labs Online — Write-up e analisi

Una raccolta di write-up di challenge e report di investigation svolti sulla piattaforma [Blue Team Labs Online](https://blueteamlabs.online/).

Questo repository documenta il mio percorso di apprendimento pratico nell'ambito della cybersecurity difensiva, con particolare interesse per l'analisi SOC, la digital forensics, il rilevamento delle minacce e l'investigazione degli incidenti di sicurezza.

## Struttura del repository

- **Challenges/** — Analisi tecniche e write-up delle challenge completate.
- **Investigations/** — Report delle attività di investigation, con evidenze, risultati e conclusioni.

## Aree di approfondimento

- Analisi di log e traffico di rete
- Digital forensics e analisi degli artefatti
- Threat detection e investigation
- Analisi di malware e file sospetti
- Indicatori di compromissione (IOC)
- Strumenti e tecniche di analisi della sicurezza informatica

*Gli argomenti e gli strumenti saranno documentati nei singoli report man mano che verranno affrontati.*
